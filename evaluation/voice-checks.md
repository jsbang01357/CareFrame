# 음성 확인 상태

2026-10-09. 가상 증례만 사용한다.

| 확인 | 상태 | 근거 |
|---|---|---|
| 서버 단기 토큰 발급 | 성공 | 실제 API HTTP 200, 토큰 값은 기록하지 않음 |
| 브라우저 음성 연결 | 사용자 성공 보고 | 실패 보고 후 사용자 답변: “ㄴㄴ 또 됨” |
| V01 첫 질문·3턴 전사·다음 질문 | 미검증 | 연결 성공만으로 전체 문답을 확인하지 않음 |
| V02 발화 중 끼어들기·입력 순서 | 실제 시험 필요 | 가짜 transport와 입력 큐 테스트만 통과 |
| V03 종료 직전 전사·마이크 해제 | 실제 시험 필요 | 가짜 transport의 track.stop 검증만 통과 |
| 긴급 고정 안내 | MP3 생성 완료, 청취 미검증 | gpt-4o-mini-tts / marin |

재현 절차: Chrome의 http://127.0.0.1:3000에서 음성 시작 → 가상 문장 “사흘 전부터 명치가 쓰려요” → 위험 질문에 답변 → 질문 도중 발화 → 마지막 발언 직후 종료. 전사·질문 연결·출력 중단·종료 자료·마이크 사용 표시를 각각 확인한다. 실제 환자 정보는 사용하지 않는다.
