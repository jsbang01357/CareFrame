# 복통 문진·의료진 검토 검증 · 2026-10-09

## 코드 검증

- `npm test`: 5개 파일, 65개 테스트 통과.
- `npm run typecheck`: 통과.
- `npm run build`: Next.js 16.4 webpack 프로덕션 빌드 통과.
- 전체 개별 답변 경로, 명시적 부정/미확인 구분, 추가 위험 항목, 당뇨+구토, 클릭의 질문 연결, NRS 범위, 상세 병력 확인, 원문 버전 변경 시 검토 무효화 등을 검사했다.
- 음성은 가상 transport로 마지막 안내 시 입력 중단·늦은 전사 무시를 검사했다. 실제 마이크나 음성 청취 결과가 아니다.

## 실제 API·브라우저 검증

사용자 탭과 분리한 로컬 테스트 탭에서 가상의 30세 여성 증례를 사용했다. 실제 추출 API를 호출했으며 실패 시 고정 증례로 대체하지 않았다.

1. “사흘 전부터 명치가 쓰리고 밥을 먹으면 더 아파요. 통증은 3점이고 한 번에 10분 정도 가요.”에서 CC·위치·시작·양상·식후 악화·NRS·지속시간을 수집했다.
2. 위험 항목 10개에 아니오 클릭으로 답하고 다음 질문 진행을 확인했다.
3. 관련 증상·과거력·수술·약·알레르기 및 호전·물 섭취를 문장으로 답했다. 완화 요인은 이 답변에서 추출되지 않아 추가 질문으로 확인했다. 총 13회 답변으로 문진을 완료했다.
4. 반복되는 통증 때문에 휴식 관찰 대신 오늘 의료기관 문의·진료 안내가 표시됐다.
5. 의료진 화면에서 CC/HPI·NRS·지속시간·관련 병력과 원문 근거를 확인했다. 편집본에 가상 보충 문구를 추가하고 검토 표시 후 실제 클립보드의 보충 문구·검토 상태를 확인했다.
6. 첫 환자 발언의 시작 시점을 사흘에서 3주로 정정했다. 현재 기록은 v13→v14로 갱신됐고, 이전 편집본은 보존되면서 검토 만료·복사/인쇄 차단 상태가 표시됐다.
7. 현재 원문을 다시 불러와 검토하고 원문 패널이 열린 화면을 `screenshots/clinician-review.jpg`에 저장했다.

## 실패와 한계

- 한 번의 긴 다중 사실 답변에서 처리 실패가 발생했다. 별도 실제 추출 재시도는 성공했으므로 원인을 출력 토큰 부족으로 확정하지 않는다. 38개 필드 확장에 맞춰 출력 예산을 2,200→4,000으로 늘렸다. 이후 브라우저 완료 흐름은 성공했지만 완화 요인 추출 누락은 추가 질문으로 처리했다.
- 마지막에 추가한 약·병력 등의 예 클릭 후 상세 질문은 코드 테스트로 검사했다. 이 추가 동작의 실제 브라우저/API 재시험은 별도로 하지 않았다.
- 실제 마이크 문답·최종 안내 청취, A4/PDF 출력과 페이지 수, 실제 EMR 붙여넣기는 미검증이다.
- 행동 안내는 공개 자료를 참고한 가상 데모 규칙이다. 독립 임상 검증, 의료진 인증, 전자서명, 실제 환자용 운영 및 공개 배포를 완료한 것으로 해석하지 않는다.
