계획: GitHub push와 별개로 현재 작업 트리를 직접 빌드·배포한다. 102MB만 남은 디스크에서 테스트 시작이 ENOSPC로 실패했다. 타입 검사는 삭제된 cpx-catalog 경로의 이전 생성 캐시를 참조했다. 이전 임시 빌드 6개·검증 복사본 1개의 삭제 승인을 요청했으며 원본과 로컬 서버 파일은 삭제하지 않는다. 공간 확보 후 신규 경로 타입을 생성하고 검증을 다시 수행한다.

결과: 승인된 임시 폴더 7개를 정리해 약 6GB를 확보했다. 성공한 빌드 임시 폴더 자동 정리를 적용하고 이번 빌드에서도 확인했다. 현재 테스트 91/91, 깨끗한 격리 빌드의 TypeScript·프로덕션 빌드 및 1560개 번들 파일 키 검사 통과. 버전 `7d2fd52a-e49e-4de6-9316-7e8129049507`을 직접 배포하고 공개 BUILD_ID 일치·화면·health 200·Origin 차단 403·양쪽 음성 토큰 200·가상 답변 추출 200·마지막 요약 200을 확인했다. 일반 시스템 DNS 조회도 이번 API 검증에서 정상 동작했다. 루트의 오래된 생산 타입 파일은 보존했으며 로컬 단독 타입 검사에는 캐시 오류가 남아 있다. 실제 마이크 청취는 별도다. GitHub commit·push 및 자동 배포 활성화는 이번 작업에서 수행하지 않았다.

계획: `.github/workflows/deploy.yml`에서 테스트·타입·Workers dry-run 성공 후 main만 배포한다. PR에는 배포 권한을 전달하지 않는다. OpenAI 키는 기존 Worker secret에만 유지하며 CI에는 Cloudflare 배포 토큰만 필요하다. 성공 후 무료 health 요청으로 배포 상태를 확인한다. 기존 실패 기대값은 요청된 문진 계속 정책에 맞추고 응급 안내·근거 유지 검증은 강화한다.

검증: YAML 구조·공식 Actions 커밋 고정·타입·빌드·dry-run 통과. 준비한 Git index만 임시 checkout으로 복사해 테스트 84/84 및 타입 검사 통과. 별도 진행 중인 추출 변경은 제외했다(현재 작업 트리에서는 91/91). 환경 파일 없는 빌드 디렉터리에서 CI용 번들 검사도 통과했다. commit·push는 자동 승인 검토가 거절해 실행되지 않았다. 사용자에게 준비된 27개 파일의 main commit·push 승인을 요청했고 Cloudflare 토큰 등록도 요청했다. 인증·GitHub 실행·사이트 갱신은 아직 미확인이다.

## 해석 실패 원문 보존 · 2026-10-09
- [x] 범위 근거 불일치가 API 오류·음성 중단으로 이어지는 경로 확인

- [x] 모델 해석 거절·출력 형식 오류도 원문 저장으로 처리, 해석 재시도 대기 제거

계획: 검증 자체는 유지하되 모델 해석 실패로 사용자 발언을 거절하지 않는다. 잘못된 범위 인용은 uncertain으로 낮춰 기존 범위를 유지하고, 검증 가능한 다른 사실은 반영한다. 해석이 비면 해당 질문을 unclear로 표시하고 원문을 저장한 뒤 확인/다음 질문으로 진행한다. 실제 통신·한도 오류는 기존 오류 경로를 유지한다.

결과: 범위 근거 불일치·잘못된 사실 인용은 후보별로 제외하고 원문을 기록한다. 해석 가능한 다른 사실·위험 신호는 유지하며, 해석이 없으면 질문 항목을 불명확 상태로 기록한다. 해석 거절·출력 형식 오류도 원문 보존으로 처리한다. 근거 검증 때문에 모델을 다시 호출하지 않아 15초 화면 제한 시간 내 재시도 지연도 제거했다. 음성 콜백은 API 성공을 받으므로 이 해석 오류 때문에 중단되지 않는다.
검증: 모델 응답을 가짜로 제공한 실제 API 핸들러 테스트에서 범위 근거 불일치 입력이 HTTP 200으로 저장되고, 다음 답변도 HTTP 200으로 처리된다. 관련 51개 테스트·타입 검사·diff 검사 통과. 전체는 91개 중 82개 통과, 기존 위험 신호/종료 기대 관련 실패 9개가 동일하게 남았다. 실제 마이크·실제 모델 응답의 청취 검증은 하지 않았다.
