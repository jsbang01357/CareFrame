## 범위 확인 질문에서 음성 문진 종료 · 2026-10-09
- [x] `q_scope`의 짧은 긍정 답변이 직접 처리되지 않는 경로 재현
- [x] 범위 질문의 긍정·부정·모름을 질문 근거와 연결해 직접 처리
- [x] 모델 추출에도 실제 질문 문구 전달, 다른 질문의 간접 답변 사용 차단
- [x] 전체 테스트·타입 검사·로컬 API에서 범위 질문 이후 진행 검증
- [ ] 실제 마이크 재시험

계획: 추출·근거 검증을 최소 수정한다. 범위 확인만 갱신하고 증상·위험 없음·정확한 위치를 임의 생성하지 않는다.

결과: `q_scope`에 연결된 “네/예/맞아요”는 지원 범위를 확인하고 다음 질문으로 진행한다. “아니요”는 범위 밖, “모름”은 미확인으로 유지한다. 질문 연결이 없거나 다른 질문의 답변이면 범위를 확정하지 않는다.
검증: 전체 테스트 51/51 및 타입 검사 통과. 로컬 API에서 범위 질문→“네”→가슴 통증 확인→“아니요”→호흡곤란 확인→“없어요”→실신 확인의 연속 진행 확인(음성 전사 형식, 실제 마이크·외부 API 미사용). 별도 문진표 작업으로 변경된 경고 위치에 맞춰 테스트를 갱신했으며 미완료·긴급 안내 검증은 유지했다. 브라우저의 일시적 CSS 누락 오류는 현재 사라졌다.

## 실제 음성 세션의 조기 종료 원인 수정 · 2026-10-09
- [x] 브라우저 원문·종료 사유 확인: “가슴 나쁘다.” 1회 답변 → 지원 범위 밖으로 종료
- [x] 성인 본인 공통 문진으로 범위 수정, 부위만으로 자동 종료하지 않기
- [x] 질문 상한을 필수 항목·추가 확인에 맞추고 종료 이유 검증
- [x] 실제 추출 API와 공통 문진 전체 완료 흐름 검증
- [ ] 실제 마이크에서 수정된 공통 문진 전체 진행 재시험

계획: 기존 48개 CPX 초안은 활성화하지 않고 공통 병력 수집 흐름을 사용한다. 명확한 현재 위험 신호와 타인·소아 경계는 보존한다. `data/protocol.ts`, 추출 프롬프트, 엔진/요청 상한, 화면 범위 안내와 회귀 테스트를 최소 수정한다.

결과: 부위가 명치·상복부가 아니라는 이유로 문진을 종료하지 않는다. 짧은 주호소를 명확한 위험 신호로 추정하지 않으며 현재 위험 질문으로 확인한다. 필수 항목 13개를 한 항목씩 답할 수 있도록 공통 답변 상한을 24회로 통일하고 세션 시간은 15분으로 조정했다. 프로토콜 버전은 `adult-common-intake-demo-2`다.
검증: 전체 테스트 53/53·타입 검사 통과. 실제 `/api/turn` 및 추출 API로 “가슴 나쁘다.” → interviewing/supported/가슴 증상 확인 질문을 확인했다. 가상 발목 증례는 주호소·6개 위험 질문·시작 시점·양상·생활 영향·복용약·걱정의 12회 답변 후 review/complete, 최종 확인 후 finished/complete까지 진행됐다. 한 항목씩 수집하는 13회 이상 흐름은 코드 테스트로 완료·확인까지 검증했다. 실제 마이크 재시험은 아직 하지 않았다.
프로덕션 빌드도 통과했다. 변경 전 열린 세션은 이전 프로토콜 버전을 사용하므로 새로고침 후 새 대화로 검증해야 한다.
